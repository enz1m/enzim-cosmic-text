# enzim-cosmic-text

An independently maintained enzUI fork of [cosmic-text](https://github.com/hecrj/cosmic-text).

Retained text layout, bounded editor work, emoji fallback, desktop font rendering and exclusion flow.

The canonical repository is [enz1m/enzim-cosmic-text](https://github.com/enz1m/enzim-cosmic-text).
Upstream crate names, history and license notices are retained.

Git LFS is required for the upstream test fonts and images.

```sh
git clone --branch enzim https://github.com/enz1m/enzim-cosmic-text.git
cd enzim-cosmic-text
git lfs pull
```

See [FORK.md](FORK.md) for the base and patch list,
[VALIDATION.md](VALIDATION.md) for checks. The
[upstream README](README.upstream.md) is retained.
